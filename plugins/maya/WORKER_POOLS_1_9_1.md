# Worker Pool Browser — UI 1.9.1

## Changes

- Replaced backend pool management with a read-only pool browser.
- Removed New, Delete, and Save Pool actions from Maya.
- Added concise pool details and a Worker / Status table.
- Added Refresh, Use Selected Pool, and double-click selection.
- Applying a pool updates Job Setup immediately.
- Allowed and Denied Workers continue to use members of the selected pool.
- The backend remains the only source of pool definitions and membership.
