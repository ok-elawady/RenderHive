# Houdini Integration Points

- `package/renderhive.json.template` is converted to the installed package JSON.
- `payload/MainMenuCommon.xml` provides the top-level RenderHive menu.
- `payload/toolbar/RenderHive.shelf` provides the shelf tool.
- `payload/python_panels/renderhive.pypanel` reserves a dockable panel.
- `payload/python3.11libs` contains all Python packages.
- `integration/hip_events.py` owns HIP lifecycle callbacks.
