# RenderHive Houdini v2.0.0 — Production

v2.0.0 closes the Houdini submitter feature/UX gap with RenderHive Maya v2.0 while preserving Houdini-native concepts.

Release scope includes multi render sources, API 0.2.0 native pool targeting, cross-DCC job dependencies, hardware eligibility, retry/timeout, production validation, per-HIP state, support tooling, clean item-view surfaces/checkmarks and RenderHive Worker progress markers.

The package intentionally excludes a standalone Houdini installer. The final RenderHive product installer owns deployment and Houdini Package registration.

Runtime acceptance must still cover the actual studio Houdini versions/renderers and licenses used in production.
