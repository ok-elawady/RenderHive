# Bootstrap milestone 0.1.2

## Verification inside Houdini

1. Restart Houdini after installation.
2. Confirm `RenderHive` appears in the top menu.
3. Confirm the `RenderHive` shelf tab is available in the shelf tab list.
4. Open the floating window from the menu and shelf.
5. Open `New Pane Tab Type > Python Panel` and select `RenderHive`.
6. Open or save a HIP file and confirm the scene context refreshes.
7. Reopen the floating window and confirm the same window is focused instead of duplicated.
